Vault の孤立ノート(どこからもリンクされていないノート)に、繋ぐべきリンク先を意味の近さで提案する。`/lint` が「孤立している」と指摘するだけなのに対し、これは「どこへ繋ぐか」まで出す。

## 手順

1. まず索引を最新化する(増分なので変更がなければ一瞬):
   ```
   uv run --quiet {{CLAUDE_DIR}}/vault-search/vault_search.py index
   ```
2. 孤立ノートごとに候補を出す:
   ```
   uv run --quiet {{CLAUDE_DIR}}/scripts/vault-suggest-links.py
   ```
   `$ARGUMENTS`(例: `--limit 5`)で対象数を絞れる。全孤立を回すと埋め込み照会で時間がかかるため、初回や件数が多いときは `--limit` を勧める。
3. 出力は `ノートのパス → [[候補]] (距離)` の形式。距離が小さいほど意味が近い。

## 報告のしかた

- 生の羅列で終わらせない。候補の中身を Read で確認し、**本当に繋ぐ価値のある組み合わせ**だけを、なぜ繋がるのか一言添えて挙げる
- 提案は機械的な意味の近さなので、無関係な近傍が混じる。距離が近くても文脈が噛み合わないものは落とす
- 繋ぎ方の定石は2通り。どちらが妥当か示す:
  - 孤立ノート側から、関連する本文ノートへ `[[リンク]]` を本文に1行足す
  - `MOC/` 配下の適切なハブから孤立ノートへ1行リンクを張る(索引としての導線を作る)

## 落とし穴

- **索引が古いと候補もずれる。** 必ず手順1の index を先に走らせる(スキップしない)
- 索引に載っていない新規ノートは「(近い候補なし)」になる。その場合も手順1を挟めば拾える
- Ollama(embeddinggemma)がローカルで動いている必要がある。埋め込み照会がハングするようなら `ollama ps` で状態を確認する
- **勝手に編集しない。** 何をどこへ繋ぐかを提示し、承認を得てから本文に手を入れる
