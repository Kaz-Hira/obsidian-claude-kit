このセッションで得られた知見を `{{VAULT}}` にノートとして保存する。

引数があればノートのタイトルとして扱う: **$ARGUMENTS**

## まず、保存に値するか判断する

以下は保存する。

- 手間をかけて到達した分析や比較
- 理由つきの決定事項
- 後から何度も参照しそうな調査結果
- 非自明な知見

以下は保存しない。**該当するなら、書かずにその旨を伝えて終わる。**

- 答えが自明な調べもの
- 他所に文書化済みの手順
- 尾を引く知見のないデバッグ
- すでに Vault にあるもの

既存ノートと内容が重なるなら、新規作成ではなく**そのノートを更新する**。近いノートはまず**意味検索**で探す(言い回しが違う重複を Grep は見逃す):

```
uv run --quiet {{CLAUDE_DIR}}/vault-search/vault_search.py search "<保存したい内容の要旨>" -k 5
```

補助として `Grep` も使う。Ollama が落ちていて検索が失敗するときは Grep のみで判断してよい。

## 保存先

| 内容 | フォルダ | タグ |
|---|---|---|
| 恒久的な資料・知識・決定事項(既定) | `Reference/` | `ref/<話題>` |
| 自作システムの取扱説明書(スクリプト・自動化・ラボの仕様と使い方) | `System/` | `sys/<話題>` |
| 走り書き、後で消すかもしれないもの | `Memo/` | `memo/<話題>` |
| 分類が定まらない、後で仕分ける | `Inbox/` | 付けない |

**`/save` が作るのは原則 `Reference/` のノート。** 手間をかけて到達した分析や、理由つきの決定事項は恒久的な資料であり、走り書きではない。`Memo/` に書くのは、ユーザーが明示的にそう言ったときだけ。

`Blog/` には書かない(記事執筆は `obsidian-blog` スキルの領分)。`Study/` にも書かない(学習ノートは手書きの領域で、`AIコンテキスト.md` の対象外)。

タグは**既存の名前空間から選ぶ**。`ref/obsidian` `ref/claude` `ref/ai` `ref/profile`、System には `sys/ai` `sys/vault` `sys/audio` `sys/network` が既にある。新しい下位タグを作るのは、既存のどれにも当てはまらないときだけ。判断前に既存タグを確認すること。

> フォルダとタグは auto-note-mover の契約で結ばれている。`Reference/` ⇔ `ref/*`、`System/` ⇔ `sys/*`、`Memo/` ⇔ `memo/*`。
> 食い違うとノートが勝手に移動する。タグの先頭に `#` は付けない。

## 手順

1. 会話を走査し、保存に値する中身を特定する。無ければここで終わる。
2. タイトルを決める。`$ARGUMENTS` があればそれを使う。無ければユーザーに一度だけ確認する。
3. `date +%Y%m%d%H%M%S` と `date '+%Y-%m-%d %H:%M:%S'` を取得する。
4. ファイル名は **`<タイトル>.md`**(例: `Reference/Kanban運用パターン.md`)。書き込む前にユーザーに提示して確認する。uid 形式のファイル名を好むなら `<uid>.md` に変える。
5. 同名ファイルが既にあれば、**上書きせず必ず確認する**。
6. ノートを書く。
7. 関連する MOC(`MOC/` 配下)があれば、そこに `[[ノート名]]` を1行足すことをユーザーに提案する。孤立ノートを増やさないため。
8. `hot.md` は触らない。更新したければ `/hot` を使う。

## frontmatter

`template/uniquenote.md` の書式に厳密に従う。キーを増やさない。

```yaml
---
title: ノートのタイトル
aliases:
uid: "20260709103045"
created: 2026-07-09 10:30:45
updated: 2026-07-09 10:30:45
tags:
  - ref/obsidian
---
```

`uid` だけ引用符で囲む。`created` / `updated` は囲まない。既存ノートがそうなっている。

## 書き方

- 断定形・現在形で書く。会話の再現ではなく、知識そのものを書く
- ✗「〜について議論し、Claudeが〜と説明した」
- ○「〜は〜として動く。要点は〜」
- 冷えた状態で読んで理解できるだけの文脈を含める
- 言及した概念は `[[ウィキリンク]]` で結ぶ
- 見出しは `#` 一つのタイトル行から始める。既存ノートは絵文字を1つ添えることがある
