# moc-audit: MOCメンバーシップ網羅性チェック

`~/.claude/scripts/vault-moc-audit.py` を実行し、Reference/System/Study(専用MOCを
持つ3フォルダ)のノートのうち、`MOC/*.md` のどれからもリンクされていないものを
一覧する。読み取り専用。ノート・MOCファイルは一切書き換えない。

## 手順

1. `python3 ~/.claude/scripts/vault-moc-audit.py` を実行する
   (特定フォルダだけ見たい場合は `--folder Study` のように絞れる)
2. 出力された「MOC未収録」一覧をそのままユーザーに提示する
3. 件数が多い場合(目安20件超)は、タグ別に集計してどのMOCセクションに追記漏れが
   集中しているかを一言添える(判断はしない、集計のみ)
4. リンク切れ自体はこのスクリプトの対象外(`/lint` が既に検出済み)なので、
   「MOC未収録」と「リンク切れ」を混同しないこと

## 対処の選択肢(ユーザーに委ねる、勝手に実行しない)

- 該当ノートを適切なMOCセクションにリンク追加する(ユーザーが指示すれば代行してよい)
- MOCに載せる必要がないノート(下書き・作業用)なら無視してよい
- MOC自体の再編中(セクション未整備)なら、後でまとめて追記する前提で一旦保留してよい

## してはいけないこと

- MOCファイルやノートを勝手に編集してリンクを追加しない(検出のみ、追加はユーザーの指示があってから)
- 「これは重要/不要」といった価値判断をしない。一覧を出すだけ
- `/lint` が検出する項目(リンク切れ・frontmatter欠落・タグ契約違反)を再報告しない
